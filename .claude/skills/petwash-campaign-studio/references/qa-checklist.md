# Pre-delivery QA checklist — fix, don't note

Run top to bottom before delivering. A failed line gets FIXED in the package; never
ship with a violation "flagged for later".

## Brand mark & naming
- [ ] Every instance reads **PetWash™** (no space, trailing ™). Grep the draft.
- [ ] "Pet Wash Academy" spaced form used ONLY for the Academy.
- [ ] Product/platform names in English in ALL languages; LTR inside RTL copy.
- [ ] Logo referenced as the real asset; no prompt/instruction redraws it.

## Truth (A5 standard)
- [ ] Zero invented numbers, counts, ratings, testimonials, reviews.
- [ ] Every factual claim appears in the Compliance Log with a status.
- [ ] Only the known-true facts used unverified (₪55 wash, 5% member flat,
      ₪150/₪220/₪400 packs, Wald Park 05:30–23:00 exc. holidays); anything else
      is TO VERIFY or removed.
- [ ] No "verified/certified/guaranteed/insured" wording unless cleared.
- [ ] Discounts: never tier-scaled, never applied to marketplace services.

## Legal (Israel)
- [ ] Any price shown is total-inclusive (§17a) and carries ⚠️ LEGAL REVIEW if new.
- [ ] Gift cards / guarantees / refunds wording → ⚠️ LEGAL REVIEW.
- [ ] No employment language about providers (independent providers only).
- [ ] No medical/health claims; cosmetic wash only. No eco claims beyond
      "pet-formulated, Australian-made" class statements.
- [ ] No private addresses/names/phones; stations city/venue-level.

## Voice & craft
- [ ] Hebrew reads native-premium (no translated-English cadence, no slang).
- [ ] English reads global-luxury, not local-translation.
- [ ] No hype vocabulary, no exclamation stacking, no urgency theater.
- [ ] Visuals: stage-white / ink-black / gold #D4AF37 single accent only;
      no purple, no neon, no gradients-as-style, no cartoon mascots.
- [ ] Motion described as slow and physical; sound diegetic-first.

## Package integrity
- [ ] All 7 sections present (or the single component requested, full quality).
- [ ] Brief recap states every assumption made.
- [ ] Cutdowns reuse hero shots (no orphan footage).
- [ ] Every AI prompt ends with the standard negative list + a Post: note.
- [ ] Exactly one alternate concept, two lines, at the end — or none.
