# 🔒 .replit Configuration Lock - MANDATORY FOR DEPLOYMENT

**Created**: November 21, 2025  
**Purpose**: Prevent deployment failures caused by incorrect port configuration

---

## 🚨 CRITICAL DEPLOYMENT RULE

**Autoscale deployments ONLY support ONE external port.**

Multiple ports will cause your deployment to:
- ❌ Hang indefinitely
- ❌ Fail silently
- ❌ Never become accessible

---

## ✅ MANDATORY .replit Port Configuration

Your `.replit` file **MUST** contain exactly **ONE** `[[ports]]` block:

```toml
[[ports]]
localPort = 5000
externalPort = 80
```

### ❌ FORBIDDEN: Multiple Port Blocks

**DO NOT DO THIS:**
```toml
[[ports]]
localPort = 5000
externalPort = 80

[[ports]]
localPort = 3000
externalPort = 3000

[[ports]]
localPort = 8080
externalPort = 8080
```

This configuration will **break all deployments**.

---

## 🛡️ Automated Protection

The **PetWash™ 2025 Preflight Guardian** automatically enforces this rule:

### When Preflight Runs
```bash
npm run preflight
# or
npm run build  # (runs preflight automatically via prebuild hook)
```

### What It Checks
1. **Counts `[[ports]]` blocks** in `.replit` file
2. **If more than 1 found** → Hard failure, blocks deployment
3. **Clear error message** with fix instructions

### Example Output (Port Error Detected)
```
📊 Preflight Report

--- PORT_ERROR (1) ---
• 🚨 DEPLOYMENT BLOCKER: Found 16 [[ports]] blocks in .replit file. 
  Autoscale deployments ONLY support 1 external port. 
  Your deployment will FAIL or HANG. 
  Fix: Keep only [[ports]] with localPort=5000, externalPort=80. 
  Remove all other port blocks.  -> .replit

❌ Preflight failed.
These issues must be fixed before build, deploy or pushing to protected branches.
```

## 📁 Build Directory Lock

The preflight guardian also enforces that production builds use **dist/public ONLY**.

### ✅ CORRECT Build Output
```
dist/
  └── public/
      ├── index.html
      ├── assets/
      └── brand/
```

### ❌ FORBIDDEN Build Directories
- `public/` (wrong output directory)
- `build/` (wrong output directory)
- `out/` (wrong output directory)

If the preflight detects `index.html` in any forbidden directory, it will block deployment with:
```
--- BUILD_DIR_ERROR (1) ---
• 🚨 DEPLOYMENT BLOCKER: Found built files in public/. 
  This indicates wrong build configuration. 
  Production MUST use dist/public only. 
  Delete public/ and ensure vite.config.ts outputs to ../dist/public.
```

## 🔧 How to Fix Port Configuration

### Step 1: Open .replit File
In your Replit workspace, click `.replit` in the file tree.

### Step 2: Find All `[[ports]]` Sections
They look like this:
```toml
[[ports]]
localPort = XXXX
externalPort = YYYY
```

### Step 3: Delete All Except One
Keep only:
```toml
[[ports]]
localPort = 5000
externalPort = 80
```

Delete all other `[[ports]]` blocks completely.

### Step 4: Save & Test
```bash
npm run preflight
```

You should see:
```
✅ No issues found. Codebase looks clean and modern.
You are safe to build, deploy and push to GitHub.
```

## 📋 Deployment Checklist

Before clicking "Deploy" in Replit:

- [ ] Run `npm run preflight` - no PORT_ERROR or BUILD_DIR_ERROR
- [ ] Verify `.replit` has exactly 1 `[[ports]]` block
- [ ] Verify `localPort = 5000` and `externalPort = 80`
- [ ] Check `dist/public/index.html` exists after build
- [ ] No `public/index.html` or `build/index.html` exists
