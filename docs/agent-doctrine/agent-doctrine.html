01 · The doctrine

Three lanes. Nobody crosses unreviewed.

Speed comes from the right hands doing the right work — not from any one agent doing everything.

Codex generates. Claude judges. Xcode ships. A human signs off at every gate.

Each lane is best at one thing and weak at the others. Codex is fast hands with no judgment. Claude is judgment with no shipping authority. Xcode is the only thing that actually builds, signs, and reaches a real iPhone. Keep them in their lanes and the whole organism stays fast and safe.

06 · The golden rules

Non-negotiable for every agent

Root cause, never a band-aid. No fix that hides a defect.
Remove stale code; never duplicate a system. One identity service, one ledger, one design system.
Temp hacks carry an expiry note + removal task. Tracked, not forgotten.
Risky change → feature flag + documented rollback. Always reversible.
Small, reviewable, revertible PRs. No giant merges.
No AI-generated code reaches main unreviewed. A human reviews; Xcode compiles; then it ships.
