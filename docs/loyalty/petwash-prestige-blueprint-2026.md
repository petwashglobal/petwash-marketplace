# PetWash Prestige — Loyalty Blueprint 2026

Stealing the best from the world's top programs and making it *ours* — luxury, bilingual,
every word crafted (never google-translated). Internal tier IDs stay (`bronze/silver/gold/
platinum`) so code doesn't break; this is about **mechanics + experience + copy**.

## What we steal, and from whom

| Source | The idea | PetWash move |
|---|---|---|
| **Booking.com Genius** | Instant status on signup; **never expires** | Enroll = perks from minute one; status never decays. Zero friction, lifetime. |
| **Sephora Beauty Insider** | Trade points for **experiences**, not just discounts | Redeem points for a spa-grade groom, a private wash hour, a masterclass, or a **gift to someone you love** (ties into eGift). |
| **Marriott Bonvoy** | Elite perks + partner network | Tier-up = a free wash, priority booking, partner perks (vet, pet shop, café near stations). |
| **Delta SkyMiles** | **AI** predictive nudges | "One wash from Gold — book it and it's yours." Personalised, timed, never spammy. |
| **adidas adiClub** | Early access to **limited drops** + birthday perk | First dibs on new shop products & new station openings; a real birthday gift for pet *and* owner. |

## The three promises (the spine of the program)
1. **Instant** — perks the moment you join (Genius).
2. **Forever** — your status never expires (Genius).
3. **Beyond discounts** — points buy *moments*, not just money off (Sephora).

## Build order
1. **Instant + never-expires** mechanic (enrollment perk; remove any tier decay).
2. **Points → experiences** in the rewards catalog (already real after #727 — add experience-type rewards).
3. **AI nudges** ("X washes from next tier") — uses the real `tierProgress/tierThreshold` we already wired.
4. **Birthday engine** (pet + owner) → auto reminder + gift/booking nudge (compounds with eGift + calendar).
5. **Early-access drops** for shop + new stations (tie to tier).

Every surface: rich glassy luxury (gold-on-dark tokens), real icons, crafted HE/EN copy. No google-translate, no filler.
