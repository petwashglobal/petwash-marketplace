# PetWash Israel — Provider Onboarding, Verification, Trust & Compliance Journey

**CEO master spec, captured 2026-06-23. Israeli lawyer must review before launch. Captures the full provider compliance gate. Pairs with the live bug: real providers' steps fail to lodge to the backend (under investigation — see status).**

> **Core principle:** provider onboarding in Israel is a **controlled compliance gate, not a signup form**. A person can create an application but is NOT a live provider until PetWash Support/Admin **manually approves**. No provider receives jobs until all required checks pass.

## Provider statuses
`draft → submitted → pending_review → (missing_documents | document_rejected | risk_review) → approved | approved_limited | rejected | suspended | expired_compliance`

## Israel identity problem (Step 2/5)
Support all cases, approve none automatically. `id_type`: israeli_teudat_zehut / israeli_passport / foreign_passport / permanent_resident / temporary_resident / work_visa_holder / company_representative / other_requires_manual_review. **No Teudat Zehut → enhanced review.** Collect per type (TZ number / passport number+expiry / visa+work-permit), front/back ID, **selfie/liveness**, address. Expired = reject/re-request; name mismatch = risk_review; blurry = document_rejected; foreign passport w/o right-to-work proof = cannot approve. Store only what's needed; restrict ID-doc access; secure storage; **log every admin view/download**.

## The journey (steps)
- **Step 0 — entry:** "Become a PetWash Provider" + 5 checkboxes (independent provider not employee; review before approval; may request ID/tax/insurance/safety docs; PetWash not insurance; I have legal right to provide services in Israel).
- **Step 1 — basic account:** full legal name, display name, phone(OTP required), email(verify), DOB(18+, block if under), language, city, address, emergency contact. Phone-unverified → can't continue; email-unverified → draft only.
- **Step 2 — identity document** (above).
- **Step 3 — RIGHT TO WORK in Israel** (critical for foreign/visa): citizen/resident? legal right to provide paid services? visa? restricted to employer/industry? registered business? Required uploads if not citizen/resident: visa/residence permit, work permit, lawyer/accountant confirmation, passport, address proof. Declaration. Logic: `foreign_passport → pending_review + right_to_work_review_required`; no proof → block or `cannot_approve_until_resolved`. **Foreign workers regulated → get legal advice before approving.**
- **Step 4 — business/tax status:** עוסק פטור / עוסק מורשה / חברה בע״מ / שכיר-not-registered / individual-not-registered / foreign / unsure. Collect business number (ע.מ/ח.פ), VAT status, can-issue receipt/invoice, withholding cert. Declarations (own tax reporting; issue invoices; update if changes; **commission 15%**; payouts blocked if tax docs missing/expired). Not-registered/unsure → draft only. `tax_status=pending_review` until admin approves.
- **Step 5 — services offered** (per-service questions): station_assistant, dog_wash_support, grooming, mobile_grooming, dog_walking, pet_sitting_customer_home, pet_sitting_provider_place, overnight_hosting, transport, training, photography, delivery. **Provider can be approved per service** (e.g. approved walking, not hosting until premises+insurance approved).
- **Step 6 — pet safety & animal-care declaration:** experience + scenario questions (anxious dog, bite, escape, sick pet, unsafe owner instruction) + 6 declarations (care/no-violence/follow-rules/stop-if-unsafe/no-unapproved-locations/no-unauthorised-handlers). Optional Academy quiz, must pass.
- **Step 7 — trust/character screening:** criminal checks legally sensitive — **no reckless "upload criminal record"; lawyer-approved process only.** Declarations (no animal-cruelty conviction; not prohibited; not banned by another platform; no restriction; may request docs where lawful; false declaration → rejection/legal action). Sensitive services (overnight, hosting, transport, key/access, high-value pets, vulnerable customers) → `enhanced_trust_review_required`.
- **Step 8 — insurance declaration:** company/policy/coverage/expiry/covered-services/upload + public/professional/product/vehicle/hosting liability. "PetWash is not an insurer; I hold valid insurance." Missing required insurance → service blocked (can submit, can't be approved for that service). Expired → remove badge, block service, reminder, `compliance_status=expired`.
- **Step 9 — bank/payout:** bank/branch/account/holder-name/confirmation-upload, ILS, business/personal. Holder-name should match provider/business → mismatch=risk_review; same account across unrelated providers=risk_review; foreign bank=manual.
- **Step 10 — address & place safety:** all providers (city/area/radius). **Hosting → detailed host-place form** (property type, own/rent, landlord permission, fenced yard, balcony, stairs, pool/water, children/adults/animals at home, max pets, separation rooms, AC/shade, cleaning, emergency vet, photos) + safe-premises declaration. **Admin approval required for hosting.**
- **Step 11 — availability (worker-classification protection):** provider controls own schedule (days/hours/area/max-jobs/notice/vacation/accept-decline). Avoid employee-like language (no fixed shifts/salary/"staff"); use "independent provider". **Israeli platform-worker classification is legally active (Wolt) — employment lawyer must review before scale.**
- **Step 12 — pricing:** provider sets, platform minimums (no 0/nonsense), show 15% commission + estimated payout. (Min-price floors already built: `shared/providerMinPrices.ts`.)
- **Step 13 — legal contracts + digital signature:** must accept/sign before submit: 1 Independent Contractor Agreement, 2 No-Employment Declaration, 3 Tax/Invoice Declaration, 4 Insurance Responsibility, 5 Not-Insurance Disclaimer, 6 Animal Welfare/Safe Handling, 7 Privacy/DPA Notice, 8 No-Off-Platform-Payment/No-Poaching, 9 Host Premises Addendum (if hosting), 10 Customer Premises Addendum (if entering homes), 11 Transport Addendum (if transport), 12 Brand/IP Rules, 13 Incident Reporting Rules. Each acceptance stores: type, version, language, timestamp, IP, device_id, app_version, checkbox, signature, PDF snapshot, provider_id, tenant=IL.
- **Step 14 — final review summary + Submit** → `submitted`.

## Automated checks after submit (set risk_score green/yellow/orange/red)
Identity (fields complete, not expired, selfie, phone/email verified, 18+); doc quality (readable/not-empty/allowed-type/not-dup); tax (status + docs + business-number format); insurance (required? expiry, upload); bank (present, confirmation, name-match, dup-risk); fraud (dup phone/email/ID/device, same-bank, self-booking, repeated attempts); service safety (hosting→place review, transport→vehicle/insurance, home-access→enhanced trust).

## Admin review dashboard + decisions
Tabs: new / missing-docs / risk-review / foreign-passport-right-to-work / host-place / insurance / tax / ready-to-approve / rejected / suspended / expiring. Decisions: **approve fully / approve limited (per service) / request docs (missing_documents) / reject document (structured reasons) / risk_review / reject / suspend.** Structured rejection reasons: identity_blurry/expired/name_mismatch, passport_expired, visa_missing, right_to_work_unclear, tax_missing/unclear, insurance_missing/expired/not-covering-service, bank_missing/mismatch, host_place_missing/unsafe, signature_missing, wrong_document, manual_review_required.

## Risk score → approval authority
GREEN (Israeli ID, clear, safe services) → trained support can approve. YELLOW (minor missing/new/limited exp) → approve with limits. ORANGE (foreign passport, right-to-work unclear, mismatch, host concerns, sensitive service, incomplete insurance) → senior review. RED (fake doc, false declaration, unsafe handling answer, dup identity, fraud, no legal right, dangerous premises) → cannot approve without legal/management.

## Badges (only real ones), training, privacy
Badges auto-disappear on expiry: ID/Phone/Tax/Insurance Verified, Safety Trained, Host Place Reviewed, etc. Academy training (10 modules) + quiz, renew every 12 months. **Privacy:** collect-minimum, restrict admin access, encrypt, audit logs, retention policy, access/deletion requests — **Amendment 13 (Aug 2025)** review required; never SMS sensitive data; never expose docs to others.
