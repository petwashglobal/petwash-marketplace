Create

Confirm

	•	wallet_debited_cents = wallet_hold_cents

	•	lifetime_redeemed_cents increases

Decline
	•	finance_state = released
	•	wallet_release_key written
	•	available balance restored
	•	pending balance returns to zero
	•	no duplicate release on retry

Cancel after debit
	•	finance_state = refunded
	•	wallet_refund_key written
	•	wallet_refunded_cents = wallet_debited_cents
	•	available balance restored
	•	no duplicate refund on retry

Admin validation after each scenario:

	•	pending balance matches holds
	•	division report shows walkers, sitters, academy correctly
