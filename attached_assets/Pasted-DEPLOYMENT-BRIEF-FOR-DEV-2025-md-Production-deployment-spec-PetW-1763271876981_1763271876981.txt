DEPLOYMENT_BRIEF_FOR_DEV_2025.md
================================

Production deployment spec – PetWash platform (Replit + Google Cloud + Firebase)
Version: Nov 2025

GOAL
----
1. אתר petwash.co.il ו www.petwash.co.il נטענים בלי מסך לבן.
2. בניה אחת לכולם:
   - Vite/React frontend (multi business units)
   - Express server (REST API + SSR shell only if צריך)
3. שימוש מלא בביו-מטרי שכבר עובד:
   - Google Cloud Storage bucket: signinpetwash.firebasestorage.app
   - Prefix: biometric-certificates/
   - Lifecycle rule קיים למחיקה אחרי 1 יום.

IMPORTANT – WHAT IS ALREADY WORKING
-----------------------------------
1. Replit Deploy logs:
   - Build: "vite build" רץ בהצלחה (ללא error).
   - Autoscale service נוצר.
   - Logs ביומטרי:
     [BiometricStorage] Google Cloud Storage client initialized
     [BiometricStorage] Bucket "signinpetwash.firebasestorage.app" verified
     [BiometricStorage] Lifecycle rule already configured on signinpetwash.firebasestorage.app

2. DNS:
   - petwash.co.il → A 34.111.179.208
   - www.petwash.co.il → A 34.111.179.208
   - TXT replit-verify=... קיים
   - SSL תקין.

3. הבעיה הנוכחית:
   - HTML הראשוני כנראה חוזר (אין שגיאת 502 כרגע).
   - המסך לבן כי ה JavaScript של ה Vite bundle לא נטען או נזרקת שגיאה בזמן ריצה.
   - היה file בשם deploy.ts שניסה לעשות לוגיקת deploy, כנראה לא מתאים יותר.

מטרה למפתח:
   - לפשט את ה deployment.
   - להשתמש ב pattern סטנדרטי של 2024–2025 ל Vite + Express.
   - לוודא שה build נקי, ה server משרת את dist, וכל error בצד client נרשם ללוג כדי לא נראה שוב מסך לבן שקט.

STRUCTURE OVERVIEW
------------------
Root:
  package.json
  server/
    index.ts        ← main Express entry point
    biometricStorage.ts  ← כבר קיים ועובד, לא לגעת חוץ מ import
  dist/             ← נבנה על ידי "vite build"

No special deploy.ts. אם קיים deploy.ts או deploy.js – לבטל מה production.

==================================================
1. package.json – scripts and engines (single source of truth)
==================================================

להגדיר כך (להתאים רק אם כבר קיימים scripts נוספים). חשוב שהסקריפטים הבאים יהיו קיימים:

{
  "name": "petwash-platform",
  "version": "1.0.0",
  "private": true,
  "scripts": {
    // Local dev
    "dev": "vite",

    // Production build
    "build": "vite build",

    // Run compiled server in production
    // Replit deployment will call THIS
    "start": "node dist/server/index.cjs",

    // Optional: healthcheck script for debugging
    "healthcheck": "node scripts/healthcheck.js"
  },
  "engines": {
    "node": ">=20.0.0"
  }
}

הערות:
- אם כבר יש סקריפט "build" שעובד, להשאיר אך לוודא שהוא מריץ "vite build".
- כל קובץ deploy.ts שהוסף קודם לא יופעל יותר. אנחנו לא משתמשים ב npm script "deploy" כדי להעלות את Replit. רק build + start.

==================================================
2. server/index.ts – single Express entry for API + static frontend
==================================================

בקובץ server/index.ts להגדרה מודרנית (Node 20, TypeScript). אם יש קוד קיים, אפשר למזג, אבל המינימום צריך להיראות ככה:

// server/index.ts

import path from "node:path";
import fs from "node:fs";
import express from "express";
import helmet from "helmet";
import cors from "cors";

// Biometric storage already implemented and working
import { initBiometricStorage } from "./biometricStorage";

const app = express();

// 1. Basic security hardening
app.use(helmet({
  contentSecurityPolicy: false // אם צריך CSP נעשה בהמשך
}));

// 2. JSON parsing
app.use(express.json());
app.use(express.urlencoded({ extended: true }));

// 3. CORS – allow main domains only
const allowedOrigins = [
  "https://petwash.co.il",
  "https://www.petwash.co.il",
  "https://pet-wash-il-nirhadad1.replit.app"
];

app.use(cors({
  origin: function (origin, callback) {
    if (!origin) return callback(null, true); // mobile apps, curl וכו'
    if (allowedOrigins.includes(origin)) {
      return callback(null, true);
    }
    console.warn("[CORS] Blocked origin:", origin);
    return callback(new Error("Not allowed by CORS"));
  },
  credentials: true
}));

// 4. Biometric storage init (already confirmed in logs)
initBiometricStorage().catch((err) => {
  console.error("[BiometricStorage] Failed to init:", err);
});

// 5. Simple healthcheck for Replit and for us
app.get("/healthz", (_req, res) => {
  res.status(200).json({ ok: true, time: new Date().toISOString() });
});

// 6. API routes – כאן לחבר את כל ה routers הקיימים
//    לדוגמה:
// import apiRouter from "./api";
// app.use("/api", apiRouter);

// 7. Serve static frontend from dist
const distDir = path.resolve(__dirname, "..", "public"); // לפי איך שה build מסדר
const indexHtmlPath = path.join(distDir, "index.html");

if (!fs.existsSync(indexHtmlPath)) {
  console.error("[Startup] dist/index.html not found. Did you run `npm run build`?");
}

app.use("/assets", express.static(path.join(distDir, "assets"), {
  maxAge: "7d",
  immutable: true
}));

app.use(express.static(distDir));

// 8. Catch-all route – return index.html for SPA routes
app.get("*", (_req, res, next) => {
  fs.readFile(indexHtmlPath, "utf8", (err, html) => {
    if (err) {
      console.error("[Startup] Failed to read index.html:", err);
      return next(err);
    }
    res.setHeader("Content-Type", "text/html; charset=utf-8");
    res.send(html);
  });
});

// 9. Error handler – so we do not get silent white screen
app.use((err: any, _req: express.Request, res: express.Response, _next: express.NextFunction) => {
  console.error("[Express Error]", err);
  res.status(500).json({
    error: "Internal Server Error",
    message: process.env.NODE_ENV === "development" ? String(err) : "Unexpected error"
  });
});

// 10. Start server
const port = Number(process.env.PORT || 5000);
app.listen(port, () => {
  console.log(`[Server] Listening on port ${port} in ${process.env.NODE_ENV || "development"} mode`);
});

export default app;

הידור ל JS:
- TypeScript יקמפל את server/index.ts ל dist/server/index.cjs (או js) לפי tsconfig.
- חשוב ש Replit deployment יריץ בדיוק את הקובץ הזה דרך "npm run start".

4. Environment variables – what must exist (values Nir can manage)
==================================================

Nir already maintains secrets in Replit. חשוב רק לוודא שקיימים הקיז הבאים:

Required for biometric storage:
  - FIREBASE_SERVICE_ACCOUNT_KEY   ← JSON service account for signinpetwash project
  - FIREBASE_PROJECT_ID            ← "signinpetwash"
  - BIOMETRIC_BUCKET_NAME          ← "signinpetwash.firebasestorage.app"
  - BIOMETRIC_PREFIX               ← "biometric-certificates/"

Required for web server:
  - COOKIE_SECRET
  - SESSION_SECRET
  - JWT_SECRET
  - JWT_REFRESH_SECRET

Optional but recommended:
  - SENTRY_DSN (if using Sentry)
  - NODE_ENV="production"

Nir will not change the values, רק יוודא שהמפתחות קיימים ב Replit Secrets.

6. Steps to clean old deployment logic
==================================================

1. Remove deploy.ts or deploy.js from server codebase if it exists.
   - If משהו אחר משתמש בו לכלי פנימי – לא לקרוא לו ב production.
   - לדאוג שאין "npm run deploy" בשימוש ב Replit.

2. Check package.json:
   - Confirm that deployment in Replit uses the "build" and "start" scripts only.
   - No "prestart" or "poststart" scripts שעושים דברים מסובכים בלי צורך.

3. Ensure Vite build outputs to a predictable folder:
   - In vite.config.js:
     export default defineConfig({
       build: {
         outDir: "dist/public"
       }
     });
   - זה מה שמאפשר ל server/index.ts לשרת את dist/public כ frontend.

4. Commit changes and trigger new Replit deployment:
   - git add .
   - git commit -m "Simplify deployment and static serving for Replit 2025"
   - push (if using remote)
   - In Replit: Publish → wait for green.

==================================================
7. After deployment – debugging the white screen
==================================================

אחרי שהמפתח מיישם את מה שמעל, Nir צריך לבצע:

1. Test on iPhone / iPad / Mac:
   - Safari: open https://petwash.co.il
   - Chrome: open https://petwash.co.il
   - If page still white:
     - Open Developer Tools → Console (ב Mac)
     - לצלם שגיאות JS אם יש.

2. Check /healthz:
   - Go to https://petwash.co.il/healthz
   - Expect JSON: { "ok": true, "time": "..." }
   - אם /healthz נכשל, יש בעיה ב Express.

3. If assets not loading:
   - Check Network tab that:
     - /assets/index-*.js returns 200.
   - If 404 on assets → לבדוק path ב server/index.ts וב vite.config.js.
