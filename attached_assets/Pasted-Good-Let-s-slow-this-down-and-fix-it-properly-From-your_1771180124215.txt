────────────────────────
PART 1 — GOOGLE SIGN IN STUCK AFTER SELECTING ACCOUNT
────────────────────────

When Google opens and lets you choose an account, that means:

✔ OAuth client ID is valid
✔ Firebase project is connected
✔ Google provider is enabled

If it hangs after selecting account, usually one of these is wrong:

A) Authorized domains missing
Go to:

Firebase Console → Authentication → Settings → Authorized domains

You MUST see:
	•	your production domain (petwash.co.il or whatever you use)
	•	signinpetwash.firebaseapp.com
	•	your custom subdomain if using one
	•	localhost if testing

If any is missing → add it.

B) OAuth redirect URI mismatch
Go to:

Google Cloud Console → APIs & Services → Credentials → OAuth 2.0 Client IDs

Open your Web Client ID.

Under “Authorized redirect URIs” you MUST see:

https://signinpetwash.firebaseapp.com/__/auth/handler

If missing → add it exactly.

Even 1 character wrong breaks redirect.

C) Third-party cookies blocked (iPad issue)
On iPad:

Settings → Safari
Turn OFF:
• Prevent Cross-Site Tracking
• Block All Cookies

Google popup needs cookies to complete handshake.

D) Replit webview issue
If you are inside Replit iOS app, sometimes popups cannot return.

Test this:
Open Safari directly → go to your production domain → try sign in there.

If it works in Safari but not in Replit app → it’s a webview restriction problem.

If reCAPTCHA spins forever, 99% it is:

Check this carefully:

Go to:
Google reCAPTCHA admin console

	•	petwash.co.il
