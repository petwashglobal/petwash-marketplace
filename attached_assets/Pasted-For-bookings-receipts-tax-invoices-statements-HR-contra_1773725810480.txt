For bookings, receipts, tax invoices, statements, HR, contracts, and records, the best setup is not one Google tool for everything. Google’s own APIs are specialized: Forms is for forms and responses, Sheets is for spreadsheet data, Drive is for files/storage, and Calendar is for events/bookings.  ￼

Best Google tool for each use case

1. Bookings

Use Google Calendar for schedule/calendar events only.
It is the right Google product for creating and updating appointments, provider schedules, and reminders through events.insert / events.update.  ￼

Use your main database as the source of truth for:
	•	booking ID
	•	customer
	•	provider
	•	status
	•	price
	•	cancellation
	•	payment state

Do not make Calendar your master booking database. Calendar is best as the scheduling layer, not the financial ledger. That follows from what the Calendar API is designed for: events and calendars.  ￼

2. Receipts / tax invoices / credit notes / statements

Do not use Google Forms for this.
Do not use Google Sheets as the primary financial record either.

Use:
	•	your database for all transaction and tax-document records
	•	Drive to store generated PDF files of receipts, tax invoices, credit notes, statements
	•	optionally Sheets for back-office review/export only

Drive is the correct Google product for file storage and file management. Sheets is fine for exports and review, but not as the main accounting system.  ￼

3. Tax invoice engine

Best practice is:
	•	generate invoice/receipt in your own backend
	•	save document metadata in your own DB
	•	save PDF copy in Google Drive
	•	optionally log summary rows to Google Sheets

That gives you:
	•	legal traceability
	•	audit trail
	•	searchability
	•	exportability

4. Google Sheets

Use Sheets for:
	•	reconciliation review
	•	finance exports
	•	sales dashboards
	•	HR trackers
	•	operational logs
	•	manual review queues
	•	provider payout review
	•	contract registers

Sheets API is built for reading and writing spreadsheet cell values and formatting, which makes it excellent for exports and operations, but not a substitute for a transactional database.  ￼

5. Google Drive

Use Drive for:
	•	PDF receipts
	•	PDF tax invoices
	•	monthly statements
	•	signed contracts
	•	HR documents
	•	onboarding files
	•	compliance docs
	•	exported reports

Drive API is specifically the file/document storage layer. It also supports watching for file changes if you need automation later.  ￼

6. Google Forms

Use Forms only for:
	•	lead forms
	•	onboarding questionnaires
	•	provider applications
	•	support forms
	•	surveys
	•	intake forms

Forms API is for creating forms and retrieving responses. It is not the right product for financial documents or transactional accounting.  ￼
