PHASE 12.12 - MANAGER CONTROL & OPERATIONAL REPORTING

GOAL
Give managers real control over the system built in 12.9–12.11.
This layer is visibility + decision making. Not execution.

-----------------------------------
T121 - MANAGER APPROVAL QUEUE
-----------------------------------

BACKEND
GET /api/manager/approvals

SQL:
SELECT 
  d.booking_id,
  s.name as station_name,
  ca.assigned_to_uid,
  ca.assigned_team_id,
  d.closure_reason_code,
  d.updated_at as requested_at,
  EXTRACT(EPOCH FROM (NOW() - d.updated_at))/3600 as age_hours
FROM booking_disputes d
LEFT JOIN bookings b ON b.id = d.booking_id
LEFT JOIN stations s ON s.id = b.station_id
LEFT JOIN case_assignments ca 
  ON ca.case_type='dispute' 
  AND ca.case_ref_id=d.booking_id 
  AND ca.is_active=true
WHERE d.closure_requested = true
ORDER BY age_hours DESC;

UI
Route: /manager/approvals

Table:
- Booking
- Station
- Assigned (uid)
- Team
- Resolution code
- Age
- Actions: Approve / Reject

RULE
Only managers access.
This is their daily queue.
