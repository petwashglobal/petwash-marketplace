7. GOOGLE CLOUD STORAGE BACKUP - BUG FIXED
=====================================================================

Before:
GCS backup code attempted to JSON.parse GOOGLE_APPLICATION_CREDENTIALS as if it were JSON text.
That is wrong when the env var is used as a file-path style convention.

Fixed:
GCS backup now resolves credentials in the correct order:
1. GOOGLE_APPLICATION_CREDENTIALS_JSON
2. GOOGLE_SERVICE_ACCOUNT_JSON
3. GOOGLE_APPLICATION_CREDENTIALS
4. FIREBASE_SERVICE_ACCOUNT_KEY

Confirmed backup targets:
- petwash-code-backups
- petwash-firestore-backups

Confirmed backup metadata:
- SHA-256 integrity hash
- Firestore audit entry per backup

Required rule:
Never assume a Google credential env var is JSON unless that specific variable is intended to hold raw JSON.

11. BOOKING CYCLE - FULL FLOW STANDARD
=====================================================================

The correct full booking flow is now:

1. User selects service
2. BookingLifecycleService creates booking
3. PostgreSQL records booking, pets, addons, escrow
4. Platform Sheets logger writes platform-specific row
5. Email confirmation is sent
6. Google Calendar event created where applicable
7. Firestore booking document written
8. Loyalty points credited
9. Confirmation returned to client

This now covers:
- sitter
- walker
- PetTrek
- K9000
- academy

Required rule:
