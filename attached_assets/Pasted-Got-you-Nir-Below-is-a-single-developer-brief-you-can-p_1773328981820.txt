PET PLATFORM – PAYMENT, WALLET & QR SYSTEM ARCHITECTURE

(Developer Implementation Guide – Israel 2026)

1. System Overview

The platform must integrate four core components:
	1.	Mobile App / Web App
	2.	Platform Backend (API + Wallet + Ledger)
	3.	Nayax Payment & Machine Control
	4.	K9000 Station Hardware (QR reader + terminal)

The platform controls:

• user accounts
• wallet balances
• gift credits
• discounts
• loyalty rewards
• provider commissions
• tax calculations
• machine activation

Nayax handles:

• card payments
• Apple Pay / Google Pay
• QR scanning hardware
• payment settlement
• machine communication

2. Hardware at Station

Each station contains:

• Nayax payment terminal
• Nayax QR / barcode scanner
• K9000 machine controller

Supported activation methods:
	1.	Card tap
	2.	Apple Pay / Google Pay
	3.	Mobile wallet QR scan
	4.	Gift code QR scan
	5.	Discount QR scan

The QR scanner must be the primary activation method for app users.

⸻

3. User Activation Flow

Wallet Activation Flow

User opens the mobile app.

User presses:

START WASH

The app generates a dynamic QR code token.

User scans QR at Nayax reader.

Reader sends token to backend validation.

If approved → backend sends command to Nayax → machine starts.

Flow:

APP
→ QR TOKEN
→ NAYAX READER
→ BACKEND VALIDATION
→ MACHINE START

⸻

4. QR Token Security (CRITICAL)

QR codes must NEVER contain money values.

QR codes must contain secure authorization tokens only.

Example token structure:

{
user_id: UUID
machine_id: ID
session_id: UUID
timestamp: UNIX
nonce: RANDOM
signature: HMAC-SHA256
}

Security rules:

• token valid for 30 seconds
• one-time use only
• cryptographically signed
• backend validation required

This prevents:

• QR reuse
• screenshot fraud
• token forgery

12. VAT Logic (Israel 2026)

VAT = 18%

All prices shown to customers must be VAT included.

Example:

Customer price = 100₪

Calculation:

Net service = 84.75₪
VAT = 15.25₪
Total = 100₪

Formula:

net = gross / 1.18
vat = gross − net

⸻

13. Nayax Processing Fee

Nayax processing fee estimated ~1%.

Example:

Customer pays = 100₪

Nayax fee ≈ 1₪

Revenue calculation:

Net revenue = gross − vat − processor_fee

Example:

100 − 15.25 − 1 = 83.75₪
