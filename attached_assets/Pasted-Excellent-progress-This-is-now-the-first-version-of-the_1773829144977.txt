My decisions now:

1. Approved direction
The current backend architecture is approved as the correct foundation.

2. QR product direction
For production, I do not want the permanent sticker to contain an expiring signed payload.
I want the permanent physical sticker to use the static machine identity approach.

So the production direction should be:
- static printed sticker contains machineId + locationId + version only
- authenticated app scan sends that machine identity to backend
- backend performs real authorization and creates the short-lived secure activation/session
- backend returns the activation result only after all checks pass

This is the correct long-term model for real machines.

3. Keep current expiring signed payload only for:
- testing
- temporary generated QR
- admin / ops tools
- dynamic machine-displayed QR if we ever add a screen
