PART 2

How To Enforce 2-Step Verification in Google Workspace

Do this yourself.

Step 1

Go to:
admin.google.com

Log in as Super Admin.

⸻

Step 2

Go to:

Security → Authentication → 2-Step Verification

⸻

Step 3

Click:

“Allow users to turn on 2-Step Verification”
Enable it.

Then:

Click “Enforcement”

Set:

Enforce 2SV for:
All users

Grace period:
7 days maximum

Save.

⸻

Step 4

Force Strong Methods

Security → Authentication → 2-Step Verification → Advanced

Disable:
SMS only authentication

Enable:
Google Prompt
Authenticator App
Security Keys

Best practice:
Require Google Prompt + backup method.

⸻

Step 5

Disable Less Secure Apps

Security → Access and Data Control → Less Secure Apps

Turn OFF completely.

⸻

Step 6

Check Admin Roles

Directory → Admin roles

Ensure:
Only you are Super Admin.

Remove unnecessary roles.

⸻

Very Important

After enabling 2SV enforcement:

Go to:
Security → Alerts

Review:
• Admin activity
• API usage
• OAuth apps
• Login attempts
