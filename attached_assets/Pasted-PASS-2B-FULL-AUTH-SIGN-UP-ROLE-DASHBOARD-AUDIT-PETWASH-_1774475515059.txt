==================================================
3. CONFIRMED AREAS THAT NEED REVIEW FOR REAL BUGS
==================================================

A. NEW SIGN-UP BUGS TO LOOK FOR
- valid phone numbers blocked by regex mismatch
- Firebase user created but backend profile creation fails, leaving zombie users
- duplicate /api/auth/session calls
- signup succeeds but no profile / no role / wrong route
- passkey or Face ID callback fires after component unmount
- broken email verification handling

B. RETURN USER LOGIN BUGS TO LOOK FOR
- Google Safari redirect returns but user not properly finalized
- local storage marker / redirect state mismatch
- session cookie lands but /api/simple-auth/me fails
- magic link prompt flow breaks on mobile
- phone OTP logs in but client state not fully synced
- generic error messages hide real auth failures

C. ROLE / DASHBOARD BUGS TO LOOK FOR
- public user routed to wrong dashboard
- provider routed to customer area
- pending provider treated as live provider
- admin / management / staff role confusion
- franchise role missing or mapped incorrectly
- hardcoded admin email lists
- multiple conflicting dashboard components
- different route guards sending users to different login pages
- onboarding pages accessible without proper guard

D. SECURITY BUGS TO LOOK FOR
- role checks only on frontend
- missing backend guard on dashboard APIs
- emailVerified bypass for admin-like access
- stale session gets privileged access
- rate limiting missing on sensitive auth endpoints
- secrets / tokens / claims leaked to logs
