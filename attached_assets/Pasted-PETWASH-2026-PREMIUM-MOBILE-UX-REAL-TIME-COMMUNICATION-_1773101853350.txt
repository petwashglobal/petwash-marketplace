==================================================
PHASE 1 — SAME-DAY HIGH-ROI IMPROVEMENTS
==================================================

Build these first because they are fast and immediately improve trust and conversion:

1. Seen / read timestamp
Requirements:
- expose exact read time
- show elegant “Seen at 14:32” behavior
- accessible on both user and provider side
- not cluttered
- tap or long press behavior is fine
- support iOS and Android touch UX

2. Contextual empty states
Do not show generic “No messages”.
Show smart states like:
- “Your chat will open once the booking is confirmed”
- “Your walk starts in 2 hours”
- “No active chats yet. Book your first service”
- “This conversation is closed but still available as archive”
Every empty state must include the next relevant CTA.

3. Session timer chip
When a provider marks “Starting now”, show a live session timer in the header.
Requirements:
- lightweight
- real-time
- elegant chip UI
- visible in active bookings only
- mobile friendly

4. Smart notification grouping
Instead of multiple noisy alerts:
- group updates per booking
- group messages per conversation
- reduce push fatigue
- update in-app bell cleanly

These 4 items should be treated as immediate quick wins.

PHASE 3 — LIVE SESSION EXPERIENCE
==================================================

7. Live GPS map card in chat
This is one of the most important differentiators.

Use cases:
- Walk My Pet
- provider on the way
- provider arriving
- live route / movement where relevant

Requirements:
- appears inside the booking chat
- updates in real time or near-real time

- privacy safe

8. Session photo burst
Requirements:

- fast upload flow
- appears inside chat as premium update

9. Pet health / care summary log

- mood / energy
- ate / drank

- notes
- anything unusual

Requirements:
- mobile-first provider input
- customer-readable card
- stored historically
- linked to booking and pet
- should support future analytics / repeat care value
