---------------------------------------------------------------------
OVERVIEW
---------------------------------------------------------------------

Prestige Pass is the universal wallet and membership system used across
the PetWash ecosystem.

It allows customers and providers to use credits across:

• Self-service wash stations (K9000 kiosks)
• Pet sitter bookings
• Dog walking services
• Pet transport (PetTrek)
• Pet academy services
• Future retail or subscription services

The wallet logic must exist **only on the backend** to prevent fraud.

Clients (apps, kiosks, website) only request redemption.

---------------------------------------------------------------------
SUPPORTED USER TYPES
---------------------------------------------------------------------

1) Public customers
2) Service providers
3) Admin/staff

Each user receives a Prestige Pass account.

---------------------------------------------------------------------
SUPPORTED BALANCE TYPES
---------------------------------------------------------------------

Every Prestige Pass wallet can contain multiple balances.

promo_balance
Temporary promotional credits

gift_balance
Credits purchased or gifted

cash_wallet_balance
Customer prepaid funds

package_washes_remaining
Prepaid wash packages

package_services_remaining
Prepaid service packages

loyalty_points
Non-redeemable points for rewards

---------------------------------------------------------------------
DEDUCTION ORDER (CRITICAL)
---------------------------------------------------------------------

Credits MUST be consumed in the following order:

1 promo credits
2 gift balance
3 package balance
4 wallet balance
5 credit card fallback

This rule must exist only on backend.

---------------------------------------------------------------------
REDEMPTION CHANNELS
---------------------------------------------------------------------

Two redemption channels exist.

---------------------------------------------------------------------
1) KIOSK REDEMPTION (K9000)
---------------------------------------------------------------------

User flow

1 open PetWash app
2 tap Prestige Pass
3 QR token generated
4 scan on kiosk
5 backend validates token
6 backend deducts credits
7 machine starts
8 wallet updates

Important rules

QR token must:

• expire in 30–60 seconds
• be signed (JWT or HMAC)
• be one-time use
• contain no balance data
• be verified by backend

---------------------------------------------------------------------
2) ONLINE SERVICE REDEMPTION
---------------------------------------------------------------------

Example services

• pet sitter
• dog walker
• pet academy
• pet transport

User flow

1 user books service
2 checkout screen appears
3 select "Pay with Prestige Pass"
4 backend validates wallet
5 credits deducted
6 booking confirmed
7 wallet updates

QR code NOT used here.

router.get("/api/prestige-pass/me", requireAuth, async (req, res) => {

    res.json(summary)

---------------------------------------------------------------------
REDEEM AT KIOSK
---------------------------------------------------------------------

router.post("/api/prestige-pass/redeem-kiosk", requireAuth, async (req, res) => {

    const { token, machineId, amountGross } = req.body

    try {

        const decoded = await PrestigePassService.verifyQRToken(token, machineId)

        if (decoded.userId !== req.user.id)
            return res.status(403).json({ error: "Token mismatch" })

        const result = await PrestigePassService.redeemKiosk({

            userId: req.user.id,
            machineId,
            amountGross

        })

        res.json(result)

    } catch (err) {

        res.status(400).json({ error: err.message })

    }

})

PRESTIGE PASS SERVICE
---------------------------------------------------------------------

class PrestigePassService {

    static async getSummary(userId) {

        const balances = await PassRepository.getBalances(userId)

        return {

            userId,
            tier: balances.tier,

            balances: {

                promo: balances.promo_balance,
                gift: balances.gift_balance,
                wallet: balances.cash_wallet_balance,
                washes: balances.package_washes_remaining,
                loyaltyPoints: balances.loyalty_points

            }

        }

    }

---------------------------------------------------------------------

    static async redeemOnline({ userId, bookingId, serviceType, amountGross }) {

        return db.transaction(async trx => {

            const booking = await BookingRepository.getBooking(trx, bookingId)

            if (!booking)
                throw new Error("Booking not found")

            const balances = await PassRepository.getBalancesForUpdate(trx, userId)

            const breakdown = this.applyDeductionOrder(balances, amountGross)

            if (!breakdown.ok)
                throw new Error("Insufficient balance")

            await PassRepository.applyBalanceUpdate(trx, userId, breakdown)

            await PassRepository.insertTransaction(trx, {

                userId,
                bookingId,
                serviceType,
                amountGross,
                ...breakdown.parts,
                transactionType: "online_redeem"

            })

            return {

                ok: true,
                bookingConfirmed: true,
                deductionBreakdown: breakdown.parts

            }

        })

    }

---------------------------------------------------------------------

    static applyDeductionOrder(balances, amount) {

        let remaining = amount

        const parts = {

            promo: 0,
            gift: 0,
            package: 0,
            wallet: 0,
            cardFallback: 0

        }

        const promoUse = Math.min(balances.promo_balance, remaining)
        parts.promo = promoUse
        remaining -= promoUse

        const giftUse = Math.min(balances.gift_balance, remaining)
        parts.gift = giftUse
        remaining -= giftUse

        const packageUse = 0
        parts.package = packageUse
        remaining -= packageUse

        const walletUse = Math.min(balances.cash_wallet_balance, remaining)
        parts.wallet = walletUse
        remaining -= walletUse

        return {

            ok: remaining <= 0,
            shortfall: remaining,
            parts

        }

    }

}

module.exports = PrestigePassService

    let url = URL(string:"https://api.petwash.co.il/api/prestige-pass/redeem-online")!

    var req = URLRequest(url:url)

    req.httpMethod = "POST"

    req.setValue("application/json", forHTTPHeaderField:"Content-Type")

    let body = [

        "bookingId": bookingId,
        "serviceType": serviceType,
        "amountGross": amount

    ] as [String : Any]

    req.httpBody = try JSONSerialization.data(withJSONObject: body)

    let (data, _) = try await URLSession.shared.data(for: req)

    print(data)

}
