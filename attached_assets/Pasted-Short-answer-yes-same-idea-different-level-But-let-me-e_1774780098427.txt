🧠 “Control Panel” vs “Control Centre”

1. Basic meaning (general tech)
	•	Control Panel = a place where you change settings
	•	Control Centre = a place where you monitor + control everything live

👉 So:
	•	Control panel = settings
	•	Control centre = operations

⸻

🐾 In your system (this is the important part)

⚙️ Control Panel (simple version)

Think:
	•	user management
	•	pricing
	•	discounts
	•	configurations
	•	machine settings

👉 Example:
	•	change wash price from ₪20 → ₪25
	•	add promo code
	•	update terms

➡️ This is more static / admin setup

⸻

🚀 Control Centre (what you actually need)

This is much bigger and more powerful.

Think:
	•	live machine status (K9000 online/offline)
	•	active sessions (who is washing right now)
	•	payments flowing (Nayax events)
	•	alerts (machine fault, low shampoo, errors)
	•	customer activity
	•	revenue dashboard
	•	remote commands (start/stop/reset machine)

👉 Example:
	•	see: “Station #12 is running now - 3 minutes left”
	•	see: “Machine offline in Tel Aviv”
	•	trigger: “Restart machine remotely”
	•	track: “Today revenue ₪4,320”

➡️ This is real-time operations brain
