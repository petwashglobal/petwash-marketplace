========================================================
PETWASH DIGITAL MEMBER CARD SYSTEM
Wallet / QR / Balance / Loyalty Architecture
========================================================


OVERVIEW
--------------------------------------------------------
The PetWash Member Card is a digital identity card that
acts as a customer wallet, loyalty card, and service
access key across the entire PetWash ecosystem.

The card can be used for:

• K9000 self wash stations
• grooming services
• pet sitter services
• dog walking
• pet transportation
• academy / training
• retail products
• online bookings

The card works via QR code and is compatible with:

• Apple Wallet
• Google Wallet
• Mobile App
• Staff POS scanner
• K9000 machine scanner


--------------------------------------------------------

--------------------------------------------------------

Example:

Example:

Member ID
Example:

QR Code
Used for scanning by machines, POS systems,
or online login.


--------------------------------------------------------
QR CODE CONTENT
--------------------------------------------------------

The QR code should NOT contain personal data.

It contains only a secure card identifier.

Example:

PW-45872043

or

petwash://card/PW-45872043


When scanned, the system queries the backend.


--------------------------------------------------------
SCAN FLOW
--------------------------------------------------------

1. QR code scanned
2. Backend retrieves customer profile
3. System displays wallet and pet data


Example system response:

Customer: Nir Hadad
Primary Pet: Bella
Balance: ₪1000
Member Tier: Premium
Last Wash: 12 Feb 2026


--------------------------------------------------------
DIGITAL WALLET BALANCE SYSTEM
--------------------------------------------------------

The PetWash card operates as a prepaid wallet.

Balance can be used across ALL services.

Supported uses:

• K9000 self wash
• grooming services
• pet sitter
• dog walking
• pet academy training
• transportation service
• retail store items
• online booking payments


Example transaction:

Service: Full Wash
Price: ₪150

Balance before: ₪1000
Balance after: ₪850


Wallet balance updates instantly in:

• mobile app
• Apple Wallet
• Google Wallet
• POS system


--------------------------------------------------------
PET PROFILE INTEGRATION
--------------------------------------------------------

Each card links to a primary pet profile.

Example backend structure:

pet_name: Bella
pet_type: Dog
breed: Golden Retriever
special_notes: Sensitive shampoo


When staff scans card they see:

Bella 🐶
Golden Retriever
Sensitive shampoo


This improves service personalization.

K9000 MACHINE INTEGRATION
--------------------------------------------------------

Customer scans QR at machine.

Example flow:

Verify balance

Deduct cost automatically


Example:

Balance before: ₪850
Balance after: ₪780


--------------------------------------------------------
API STRUCTURE (EXAMPLE)
--------------------------------------------------------

GET /wallet/card/{card_id}

Returns:

customer profile
pet profile
balance
membership tier


POST /wallet/charge

Deduct balance for service.


POST /wallet/topup

Add funds to wallet.


GET /wallet/history

Return service and payment history.


GET /wallet/pet-profile

Return pet details.
