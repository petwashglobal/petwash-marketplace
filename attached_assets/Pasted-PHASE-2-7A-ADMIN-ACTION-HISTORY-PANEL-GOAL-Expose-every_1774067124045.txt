- debit adjust

==================================================
1. BACKEND — NEW QUERY HELPER
FILE:
- server/routes/prestige-pass.ts

ADD:
- shared query builder used by both JSON endpoint and CSV export

FILTERS:
- divisionCode
- adminUid
- from
- to
- bookingId

SOURCE FILTER:
Only ledger rows where source_type/source matches one of:
- admin_override
- admin_release
- admin_refund
- admin_adjust

RETURN FIELDS:
- txnId
- adminUid
- userId
- bookingId
- divisionCode
- source
- amountCents
- balanceAfterCents
- reason
- createdAt

QUERY SHAPE:
SELECT
  txn_id,
  admin_uid,
  user_id,
  booking_id,
  division_code,
  source_type AS source,
  amount_cents,
  balance_after_cents,
  reason,
  created_at
FROM wallet_ledger_entries
WHERE source_type IN ('admin_override','admin_release','admin_refund','admin_adjust')
  AND (:divisionCode IS NULL OR division_code = :divisionCode)
  AND (:adminUid IS NULL OR admin_uid = :adminUid)
  AND (:bookingId IS NULL OR booking_id = :bookingId)
  AND (:from IS NULL OR created_at >= :from)
  AND (:to IS NULL OR created_at < :to + interval '1 day')
ORDER BY created_at DESC
LIMIT 200

NOTES:
- If admin_uid and reason currently live inside metadata_json instead of columns, read them out in SQL:
  metadata_json->>'adminUid' AS admin_uid
  metadata_json->>'reason' AS reason
- Keep this query in one helper so JSON and CSV never drift.
