==================================================
1. BOOT RECOVERY (MUST BE BULLETPROOF)
==================================================

registerCleanupRecovery() is correct direction, but confirm exact behavior:

On server start:

Query:
SELECT * FROM bay_sessions WHERE status = 'cleanup'

For each row:

IF cleanupEndsAt <= now:
→ call finalizeCleanup(sessionId) immediately

IF cleanupEndsAt > now:
→ schedule finalizeCleanup(sessionId) with remaining time

Important:
- this must be NON-BLOCKING (do not delay server startup)
- must handle multiple sessions safely
- must not duplicate timers if called twice

Add safety:
- wrap finalizeCleanup in try/catch
- log recovery actions clearly

==================================================
2. FINALIZE CLEANUP MUST BE IDEMPOTENT (CRITICAL)
==================================================

finalizeCleanup(sessionId) must be SAFE to run multiple times.

Required behavior:

IF session.status != 'cleanup':
→ RETURN (no-op)

Then inside transaction:
- set session.status = 'completed'
- clear bay.currentSessionId
- set bay.status = 'ready'

If already completed:
→ do nothing

This protects against:
- duplicate timers
- server restart overlap
- race conditions
