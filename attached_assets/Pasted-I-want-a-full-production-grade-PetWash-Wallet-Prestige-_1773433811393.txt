7. K9000 KIOSK REDEMPTION
=====================================================================

We need a secure kiosk redemption flow.

User flow:
1. user opens PetWash app or wallet pass
2. user taps Redeem / Start Wash
3. app / pass shows short-lived dynamic QR
4. kiosk / Nayax scanner reads it
5. backend validates token and kiosk identity
6. backend checks real balances
7. backend deducts credits atomically
8. backend authorizes machine start
9. wallet pass / app updates balance
10. audit and ledger written

Build:
POST /api/k9000/redeem-wash

Input should support:
- scannedCode
- kioskId
- bayId if needed
- signed machine auth headers

Do not trust client body alone for machine auth.

Upgrade kiosk auth to this model:
- X-K9000-ID
- X-K9000-TS
- X-K9000-SIGN

Validate:
- kiosk allowlist record exists
- kiosk active flag
- timestamp freshness
- HMAC signature
- machine-to-station mapping
- bay mapping if needed

Do not allow any kiosk with just a shared secret to operate every machine.
