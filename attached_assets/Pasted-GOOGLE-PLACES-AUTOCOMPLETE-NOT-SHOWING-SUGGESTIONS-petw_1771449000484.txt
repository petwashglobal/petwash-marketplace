A) FAST TRIAGE (5 minutes)
============================================================

1) Confirm the Google Maps JS script is loading on the page
- Open the page in Safari (not inside Replit webview)
- Open DevTools console (or remote debug from Mac Safari)
- Run:
  window.google && google.maps ? "MAPS LOADED" : "MAPS NOT LOADED"

If "MAPS NOT LOADED":
- The script is not injected, blocked by CSP, blocked by ad blocker, or key rejected.

2) Check the exact error from Google in Console
Look for one of these:
- "Google Maps JavaScript API error: RefererNotAllowedMapError"
- "ApiNotActivatedMapError"
- "InvalidKeyMapError"
- "BillingNotEnabledMapError"
- "RequestDenied"
- "The Google Maps JavaScript API must be loaded"
- "This page didn't load Google Maps correctly"
If any of these appear, stop and fix Section B.

3) Confirm Places library is included
The script must include:
  libraries=places
If not, Autocomplete will never return suggestions.

4) Confirm the input is truly editable (no overlay blocking taps)
On iPad sometimes a transparent overlay blocks focus.
- In console, run:
  document.activeElement
Then tap the address input.
If activeElement is not the input, something is intercepting taps.
Fix by moving the overlay behind, or set pointer-events:none on the overlay.

5) Confirm you have an actual Autocomplete instance attached
Add one log when initializing:
  console.log("Autocomplete init", !!autocompleteRef.current);

If it never logs, the init is not running, or the input ref is null.

B) MOST COMMON ROOT CAUSES (ordered by probability)
============================================================

B1) API key restrictions are wrong (most common)
In Google Cloud Console -> APIs & Services -> Credentials -> your Maps key:
- Application restrictions:
  - HTTP referrers (web sites)
- Add exact allowed referrers:
  - https://petwash.co.il/*
  - https://www.petwash.co.il/*
  - https://signinpetwash.firebaseapp.com/*
  - https://signinpetwash.web.app/*
  - (if you test dev) https://*.replit.dev/* and https://*.replit.app/*
If you use multiple domains, list them all.

B2) Places API not enabled
In Google Cloud Console -> APIs & Services -> Library, enable:
- Maps JavaScript API
- Places API
Optional but recommended:
- Geocoding API (for reverse geocode and postal code extraction)

B3) Billing not enabled on the Google Cloud project
Autocomplete requires billing. Even if you are under free tier, billing must be enabled.

B4) CSP is blocking Google scripts
If you use a strict Content-Security-Policy header, you must allow:
- script-src https://maps.googleapis.com https://maps.gstatic.com
- connect-src https://maps.googleapis.com https://maps.gstatic.com
- img-src https://maps.googleapis.com https://maps.gstatic.com data:
If CSP blocks, the script might load partially and fail silently.

B5) You are loading the script with wrong parameters
Must include:
- key=YOUR_KEY
- libraries=places
Recommended:
- v=weekly
- language=he (or dynamic)
- region=IL
Example:
https://maps.googleapis.com/maps/api/js?key=XXX&libraries=places&v=weekly&language=he&region=IL

B6) Safari privacy / adblockers
- iCloud Private Relay, content blockers, or DNS filtering can block gstatic.
Test:
- Turn off content blockers for the site
- Try on cellular
- Try Chrome iOS (still WebKit, but different settings)

import React, { useEffect, useMemo, useRef, useState } from "react";
import { Loader } from "@googlemaps/js-api-loader";

type AddressParts = {
  formattedAddress: string;
  placeId: string;
  lat?: number;
  lng?: number;
  city?: string;
  street?: string;
  streetNumber?: string;
  postalCode?: string;
  country?: string;
};

type Props = {
  value: string;
  onChange: (v: string) => void;
  onSelect: (parts: AddressParts) => void;
  language: "he" | "en";
  region?: string; // default "IL"
  placeholder?: string;
  className?: string;
};

const parseAddressComponents = (place: google.maps.places.PlaceResult): AddressParts => {
  const parts: AddressParts = {
    formattedAddress: place.formatted_address || "",
    placeId: place.place_id || ""
  };

  const comps = place.address_components || [];
  const get = (type: string) => comps.find(c => c.types.includes(type))?.long_name;

  parts.street = get("route");
  parts.streetNumber = get("street_number");
  parts.city = get("locality") || get("postal_town") || get("administrative_area_level_2");
  parts.postalCode = get("postal_code");
  parts.country = get("country");

  const loc = place.geometry?.location;
  if (loc) {
    parts.lat = loc.lat();
    parts.lng = loc.lng();
  }

  return parts;
};

export function AddressAutocomplete({
  value,
  onChange,
  onSelect,
  language,
  region = "IL",
  placeholder = language === "he" ? "הקלד כתובת" : "Type address",
  className
}: Props) {
  const inputRef = useRef<HTMLInputElement | null>(null);
  const acRef = useRef<google.maps.places.Autocomplete | null>(null);
  const [ready, setReady] = useState(false);

  const loader = useMemo(() => {
    const apiKey = import.meta.env.VITE_GOOGLE_MAPS_API_KEY as string | undefined;
    if (!apiKey) console.warn("Missing VITE_GOOGLE_MAPS_API_KEY");
    return new Loader({
      apiKey: apiKey || "",
      version: "weekly",
      libraries: ["places"],
      language,
      region
    });
  }, [language, region]);

  useEffect(() => {
    let cancelled = false;

    async function init() {
      try {
        await loader.load();
        if (cancelled) return;

        if (!inputRef.current) {
          console.warn("AddressAutocomplete: inputRef is null");
          return;
        }

        // Initialize only once per mount
        acRef.current = new google.maps.places.Autocomplete(inputRef.current, {
          fields: ["place_id", "formatted_address", "geometry", "address_components"],
          types: ["address"],
          componentRestrictions: { country: region.toLowerCase() }
        });

        acRef.current.addListener("place_changed", () => {
          const place = acRef.current?.getPlace();
          if (!place?.place_id) return;

          const parsed = parseAddressComponents(place);
          onChange(parsed.formattedAddress);
          onSelect(parsed);
        });

        setReady(true);
      } catch (e) {
        console.error("Google Maps loader failed", e);
        setReady(false);
      }
    }

    init();
    return () => {
      cancelled = true;
      // Note: Google Autocomplete has no destroy. Let GC handle it on unmount.
      acRef.current = null;
    };
  }, [loader, onChange, onSelect, region]);

  return (
    <div style={{ width: "100%" }}>
      <input
        ref={inputRef}
        value={value}
        onChange={(e) => onChange(e.target.value)}
        placeholder={placeholder}
        autoComplete="street-address"
        inputMode="text"
        className={className}
        aria-label="Address"
        style={{
          width: "100%",
          padding: "12px 14px",
          borderRadius: 12,
          border: "1px solid rgba(0,0,0,0.12)"
        }}
      />
      {!ready && (
        <div style={{ marginTop: 8, fontSize: 12, opacity: 0.7 }}>
          {language === "he" ? "טוען שירות כתובות..." : "Loading address service..."}
        </div>
      )}
    </div>
  );
}
