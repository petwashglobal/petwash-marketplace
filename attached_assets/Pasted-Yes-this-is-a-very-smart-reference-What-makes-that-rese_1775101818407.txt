Here is the smart logic for Pet Wash:

Pet Wash confirmation card should include

For every booking, wash, sitter, walker, trainer, or provider appointment, the confirmation should show:
	•	service name
	•	booking ID
	•	date and time
	•	location
	•	provider name or station name
	•	pet name
	•	booking status
	•	amount paid or wallet / package / e-gift used
	•	cancellation / modification rules
	•	support contact

Action buttons that should always exist

These are the features that make it feel premium and useful:
	•	Add to Calendar
	•	Share Booking
	•	Call
	•	Message
	•	Modify Reservation
	•	Cancel Reservation
	•	Get Directions
	•	View Receipt / Tax Invoice
	•	Rebook
	•	Download PDF summary
	•	Add to Wallet pass if relevant

Smart 2026 widgets for each booking

For a luxury modern feel, the confirmation should include mini action widgets:

1. Calendar widget

One tap:
	•	Apple Calendar
	•	Google Calendar
	•	Outlook ICS file

For sitters / walkers / trainers, include:
	•	start time
	•	end time
	•	address
	•	provider details
	•	special notes

2. Live status widget

If the service is upcoming:
	•	confirmed
	•	provider assigned
	•	provider on the way
	•	arrived
	•	in service
	•	completed

For a wash station:
	•	booking confirmed
	•	QR ready
	•	station active
	•	session started
	•	session ended

3. Smart contact widget

Show:
	•	Call
	•	Message
	•	WhatsApp if enabled
	•	support fallback

But only show direct provider contact when rules allow it.

4. Modify / cancel widget

This should be very clear:
	•	modify booking
	•	cancel booking
	•	show refund rule before user confirms
	•	show exact expected outcome:
	•	full refund
	•	partial refund
	•	no refund
	•	wallet credit
	•	e-gift restore
	•	package deduction remains or restored

5. Share widget

Allow:
	•	share booking summary
	•	share location
	•	share provider ETA
	•	share appointment details with family member

6. Receipt / finance widget

After payment:
	•	email confirmation
	•	tax invoice / receipt
	•	wallet debit summary
	•	e-gift usage summary
	•	loyalty discount shown clearly

Self Wash / station booking

Pet sitter / walker / trainer

Buttons:

	•	Modify Booking
	•	Cancel Booking
	•	Share ETA
	•	Rebook

Provider side

Provider should get:
	•	Accept / reject
	•	Add to Calendar
	•	Contact customer
	•	Navigate
	•	Mark arrived
	•	Start service
	•	Complete service
	•	Report issue

Admin / support side

Admin should get:
	•	view live booking
	•	override
	•	refund / partial refund
	•	resend confirmation
	•	send update
	•	audit trail
	•	see notifications sent

Important hidden logic

This is where it becomes truly smart:
	•	if booking changes, calendar link updates
	•	if provider changes, confirmation refreshes
	•	if booking canceled, actions disable correctly
	•	if refund issued, confirmation reflects it
	•	if no internet, action retries safely
	•	if user double taps, no duplicate action
	•	if provider rejects, customer gets updated confirmation automatically
