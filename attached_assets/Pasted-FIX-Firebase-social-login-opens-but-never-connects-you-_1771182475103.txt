FIX: Firebase social login opens, but never connects you to profile/dashboard
Copy paste checklist + code below. Follow in order.

1) Firebase Console settings (must match exactly)
- Firebase Console -> Authentication -> Settings -> Authorized domains must include:
  petwash.co.il
  www.petwash.co.il
  signinpetwash.firebaseapp.com
  signinpetwash.web.app
  localhost

2) Frontend Firebase config (authDomain must be firebaseapp.com)
- In your frontend (where you initialize Firebase), set authDomain EXACTLY to:
  signinpetwash.firebaseapp.com
- Do NOT set authDomain to petwash.co.il or web.app or replit.app

Example firebaseConfig:
const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "signinpetwash.firebaseapp.com",
  projectId: "signinpetwash",
  storageBucket: "signinpetwash.appspot.com",
  messagingSenderId: "YOUR_SENDER_ID",
  appId: "YOUR_APP_ID"
};

3) Use ONE shared firebase init file (avoid multiple app instances)
Create firebase.js (or firebase.ts) and import it everywhere:

// firebase.js
import { initializeApp, getApps } from "firebase/app";
import { getAuth } from "firebase/auth";

const firebaseConfig = {
  apiKey: "YOUR_API_KEY",
  authDomain: "signinpetwash.firebaseapp.com",
  projectId: "signinpetwash",
  storageBucket: "signinpetwash.appspot.com",
  messagingSenderId: "YOUR_SENDER_ID",
  appId: "YOUR_APP_ID"
};

const app = getApps().length ? getApps()[0] : initializeApp(firebaseConfig);
export const auth = getAuth(app);

4) Sign in with popup (Google example)
Use this exact code for login button:

// login.js
import { auth } from "./firebase";
import { GoogleAuthProvider, signInWithPopup } from "firebase/auth";

export async function loginWithGoogle() {
  try {
    const provider = new GoogleAuthProvider();
    const result = await signInWithPopup(auth, provider);
    console.log("LOGIN OK:", result.user.uid, result.user.email);
    window.location.href = "/dashboard";
  } catch (err) {
    console.error("LOGIN ERROR:", err);
    alert("Login failed. Open console for details.");
  }
}

5) Dashboard must wait for auth state (most common reason you never land in dashboard)
On dashboard page, DO NOT assume user is already available.
Use onAuthStateChanged:

// dashboard.js
import { auth } from "./firebase";
import { onAuthStateChanged } from "firebase/auth";

onAuthStateChanged(auth, (user) => {
  if (!user) {
    console.log("No user -> back to signin");
    window.location.href = "/signin";
    return;
  }

  console.log("User logged in:", user.uid, user.email);

  // Example: fill profile UI
  // document.getElementById("email").textContent = user.email;

  // Call your API with user.getIdToken() if needed:
  // user.getIdToken().then(token => fetch("/api/me", { headers: { Authorization: `Bearer ${token}` }}))
});

6) Quick debug test (run in browser console on petwash.co.il AFTER login)
- If you use modular SDK (v9+), do:
  import { getAuth } from "firebase/auth"; getAuth().currentUser
- Or just rely on your console logs from steps 4 and 5.

Expected:
- After login, dashboard console must print: "User logged in: ..."

If still stuck:
A) You probably have TWO firebase projects mixed or TWO different firebaseConfig files.
B) Or you initialized Firebase twice (one with wrong authDomain).
C) Or your routing sends you to dashboard but your dashboard immediately redirects because user is null before onAuthStateChanged runs (fixed by step 5).

Do these two checks:
- Search your codebase for "initializeApp(" and ensure it exists only once.
- Search your codebase for "authDomain" and ensure all are "signinpetwash.firebaseapp.com"
