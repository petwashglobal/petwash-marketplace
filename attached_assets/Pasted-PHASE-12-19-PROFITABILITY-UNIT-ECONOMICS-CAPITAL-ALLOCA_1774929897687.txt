--------------------------------------------------
T191 - UNIT ECONOMICS ENGINE
--------------------------------------------------

BACKEND
Build:
server/lib/unit-economics.ts

PURPOSE
Compute a normalized economics snapshot per:
- station
- franchise owner
- company-owned network
- ownership type

INPUTS
- station_settlements
- payout_failures
- reconciliation_results
- booking_disputes
- financial_approval_log
- payout_batches
- stations
- franchise_owners

OUTPUT PER ENTITY
- gross_revenue_cents
- platform_fee_cents
- station_payout_cents
- franchise_share_cents
- held_amount_cents
- blocked_amount_cents
- failed_payout_amount_cents
- approval_delayed_amount_cents
- net_releasable_contribution_cents
- friction_cost_cents
- contribution_margin_pct

DEFINITIONS
- net_releasable_contribution =
    platform_fee
  + franchise_share
  - failed_payout_amount
  - friction_cost

- friction_cost =
    disputed_amount
  + reserve_aged_over_threshold
  + failed payout retry amount
  + approval-delayed amount

- contribution_margin_pct =
  net_releasable_contribution / gross_revenue

IMPORTANT
This is not GAAP profit.
This is “operational contribution after payment friction”.

RULE
Every amount must be traceable back to settlement and treasury states.

--------------------------------------------------
T199 - DATA DISCIPLINE RULES
--------------------------------------------------

1. Never call this “net profit”
2. Never mix held / blocked / failed / delayed money into net contribution
3. Ownership model must be explicit:
   - company-owned
   - franchise-owned
4. All economics must reconcile to settlement truth
5. Fallback assumptions must be visible, not hidden
6. Signals must be deterministic and explainable
7. Comparison logic must treat company and franchise models separately first, then together
8. No duplicated formulas across backend and frontend
9. One engine computes economics, UI only renders
