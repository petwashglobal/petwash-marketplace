# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability, please report it privately.

- Email: support@petwashglobal.com
- Or open a private vulnerability report via GitHub Security Advisories

Please include:
- Description of the issue
- Steps to reproduce
- Potential impact

We aim to respond within 48–72 hours.

## Scope

This applies to:
- Payments and payouts
- Authentication and user data
- Admin/finance endpoints

## Responsible Disclosure

Please do not publicly disclose vulnerabilities until they are resolved.
